Einstieg

Adresse kopieren

Vom System-Objekt führen Links zur Liste der Kommunen und von jeder Kommune zu ihren Sitzungen, Vorlagen, Gremien und Personen. Die Übersicht {{ uebersicht_url }} nennt im Feld bodyIndex dieselben Adressen wie die Tabelle unten, für Programme in einem Abruf.

Jede Liste enthält höchstens {{ seitengroesse }} Objekte je Seite, den Link zur nächsten Seite finden Sie unter links.next. Die Schnittstelle erlaubt Abrufe aus dem Browser (CORS){% if anfragen_je_minute %} und bis zu {{ anfragen_je_minute }} Anfragen pro Minute{% endif %}. Die Lizenz der Daten legt die jeweilige Kommune fest.
